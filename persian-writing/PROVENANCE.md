# Provenance and public-export scope

This is a sanitized, portable instruction edition of a custom agent workflow. It contains no operational customer configuration, credentials, account identifiers, private evidence or deployment history. No private application source code or user media is redistributed.

This public edition is independently worded guidance derived from the custom workflow's preservation and RTL-review requirements. The private bundle also incorporated reviewed material from https://github.com/ali2000hos/persian-writing (MIT), but no upstream files or scripts are distributed here. Upstream text-cleaning scripts, document repair/audit helpers, regression fixtures, uploaded source documents and bundled font binaries are intentionally omitted. This is an instruction-only edition, not a claim to include the full private tool bundle. Fonts must be acquired separately under their own licenses. An unlicensed uploaded guidance file is not redistributed.
