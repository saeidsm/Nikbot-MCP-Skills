# Provenance and public-export scope

This is a sanitized, portable instruction edition of a custom agent workflow. It contains no operational customer configuration, credentials, account identifiers, private evidence or deployment history. No private application source code or user media is redistributed.

Independently generalized from a custom Persian lyric-and-generation workflow. Private server integration instructions, routes, production code references, provider/account configuration and task-specific identities are omitted. No provider SDK, lyric catalog, audio, prompt from a private user's song or third-party implementation is bundled. Actual provider schema and licensing must be verified separately.
