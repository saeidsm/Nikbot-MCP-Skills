# Provenance and public-export scope

This is a sanitized, portable instruction edition of a custom agent workflow. It contains no operational customer configuration, credentials, account identifiers, private evidence or deployment history. No private application source code or user media is redistributed.

Public generalized adaptation of a custom architectural-content workflow. The historical skill name is retained for discovery; no brandbook, assets, account identifiers, credentials, private publication calendar or customer project detail is included. The live private account skill remains separate.

Selected general workflow concepts originate in Jake Schincariol's instagram-agent-skill, https://github.com/Jakeschincariol/instagram-agent-skill, reviewed in the source bundle at commit d03c56bb598be770c60b201f94237e5d1a4268a6.
