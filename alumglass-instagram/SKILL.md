# Architectural Instagram content workflow

This public adaptation keeps a historical skill name but contains no account configuration, customer assets or private brand brief. Configure the target brand and account for each engagement.

## Scope and sources
Obtain the actual objective, audience, approved assets, brand voice and destination. Distinguish education, portfolio, recruitment and commercial promotion. Verify account username before reading metrics or publishing. Treat private assets and client information according to their sharing scope. Do not invent brand colors, testimonials, client names, project results or performance claims.
Engineering claims need a traceable datasheet, test report, standard or approved project record. Specify configuration and conditions where material. Glass-only performance is not automatically whole-window performance. Missing evidence calls for a nonquantified educational explanation, not a fabricated number.

## Develop the content
For a Reel, offer a few materially different opening concepts, then develop the selected one into a beat plan with separate narration, on-screen text, source asset and intended visual. Keep timing estimates approximate until verified in a render.
For a carousel, make each card advance one point: clear opening, coherent evidence/explanation, useful conclusion and one relevant call to action. Confirm copy and selected imagery before expensive rendering or publishing when required.
For captions, use a concrete opening, concise supporting information and one clear next action. Do not promise reach, sales or algorithmic favor. Provide descriptive accessibility text where supported.

## Persian and visual QA
Use the Persian-writing skill where available. Preserve نیم‌فاصله, joined glyphs and protected technical strings. Never strip all invisible Unicode characters or reverse Persian strings. Use RTL layout and isolated LTR technical spans. Check units, signs and decimal values, especially mixed-script engineering labels.
Use the approved font and licensed media. Inspect phone-sized covers, carousel cards, text safe areas and platform crops. Check the actual soundtrack rights for the requested use. Rendering is not publishing.

## Approval, scheduling and reconciliation
A prepared caption, approved draft and scheduled post are different states. Obtain the required final approval for copy, imagery, account and publication action. Confirm local timezone and date; use current platform capabilities, not stale interface assumptions.
After upload/publish, record actual platform status and post ID/link. An upload request is not proof of publication. Reconcile ambiguous responses before retrying to avoid duplicates. Do not contact users, change a calendar or publish because an analytics task requested recommendations.

## Analytics
Use real available metrics, explicit time windows and account identity. Separate paid from organic when data allows; otherwise mark unknown. Compare post age and format before ranking. Never treat unavailable data as zero. Distinguish suggested content, started work, scheduled posts and actually published posts.
