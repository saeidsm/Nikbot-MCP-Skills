# Provenance and public-export scope

This is a sanitized, portable instruction edition of a custom agent workflow. It contains no operational customer configuration, credentials, account identifiers, private evidence or deployment history. No private application source code or user media is redistributed.

Independently generalized from a custom mobile UX skill. Application name, private file/component inventory, exact dependency snapshot, release roadmap and project-specific source templates are omitted. The public guidance requires discovery of the recipient project's real stack. No private TSX templates or code is included. Expo, React Native, Apple HIG, Material Design and WCAG are reference ecosystems, not bundled dependencies or copied documentation.
