# Provenance and public-export scope

This is a sanitized, portable instruction edition of a custom agent workflow. It contains no operational customer configuration, credentials, account identifiers, private evidence or deployment history. No private application source code or user media is redistributed.

Original custom consultation-pack guidance and two authored blank templates are preserved after privacy review. The name Fable is a reviewer label, not a vendor, capability, pricing or licensing assertion. No real consultation payload, uploaded research, model response or task-specific evidence is included. The optional private skill UI icon and host metadata are omitted.
